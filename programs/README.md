# Programs

This folder stores scope, intake, and tracking information for each approved program.

## Structure

Create one directory per program, using a stable naming convention such as:

- `american-airlines/`
- `hackerone-private-program/`
- `example-program/`

Each program folder should contain:

- `README.md` — summary, scope, and intake metadata
- `scope.md` — approved targets and exclusions
- `rules.md` — allowed and disallowed testing notes
- `assets.md` — domain, app, and platform inventory
- `findings/` — issue notes and historical evidence
- `automation/` — program-specific automation tasks

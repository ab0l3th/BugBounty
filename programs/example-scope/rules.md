# Example Program Rules

## Approved activities
- Passive research only
- Publicly available metadata collection
- In-scope host validation only
- Documentation-backed scope review before automation

## Prohibited activities
- Active exploitation
- Denial-of-service testing
- Social engineering or MITM
- Customer or employee data collection
- Accessing sensitive production secrets
- Testing or scanning out-of-scope assets

## Reporting requirements
- Submit only one issue per report unless a chained issue is necessary and clearly justified
- Preserve evidence without storing sensitive customer data
- Keep all automation aligned to approved scope and policy

# Program Intake Template

Use this template for every new program or scope.

## Required files
- `scope.md`
- `rules.md`
- `guardrails.md`

## Workflow
1. Copy this folder and rename it to the program name.
2. Replace the sample scope entries with the vendor-approved scope.
3. Confirm all in-scope targets and exclusions match the policy.
4. Add passive jobs under `jobs/` only after the scope is validated.
5. Run the worker and review results locally through the dashboard.

## Safety rules
- Passive only
- In-scope only
- Approved targets only
- No data exfiltration or credential handling
- No public disclosure before policy allows it

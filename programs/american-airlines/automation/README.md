# American Airlines Automation

This directory is reserved for program-specific automation jobs and workflows.

## Scope of automation
- Passive recon only unless formally approved
- Asset validation and scope checks
- Scheduled discovery tasks
- Alerting for new or changed assets

## Guardrails
- No active exploitation without explicit authorization.
- No retention of secrets, tokens, or sensitive data.
- All results must be reviewed against current program scope.
